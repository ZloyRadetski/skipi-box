## Scope notes

- `AppState.routeRules` and the Android global route page describe persisted global routing; P04 profile routing uses profile `.conf`/`ShadowrocketRule` data. Passing P04 screen tests does not substitute for the no-profile global runtime cases, and the global runtime cases do not reopen P04.
- The global UI was already dormant in the initial/current navigation. Preserve the source-backed repository and runtime work without creating user-facing functionality the user did not request. Generic future orchestration around that dormant clipboard screen is outside this acceptance matrix; retain unrelated N01/Z01 cleanup in its own scope.
- R01 closes only after the resource-aware no-profile start path and required host checks pass. This matrix makes no claim that OS clipboard, native package selection, a global external-resource catalog, unsupported native protocols, or a global Routing screen has been implemented.
