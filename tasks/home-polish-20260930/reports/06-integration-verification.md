## Исправления при интеграции

### Реальная готовность HevTun

- Восстановлен JNI-контракт TProxyIsReady. Native readiness выставляется после успешного hev_socks5_tunnel_init; Kotlin проверяет готовность и существование рабочего потока.
- Удалена проверка «два раза isRunning», которая не подтверждала завершение инициализации туннеля. Ошибки загрузки библиотеки больше не скрываются.
- Готовность сбрасывается при старте/остановке; завершившийся поток не считается готовым. Таймаут запуска выполняет очистку.
- Диагностика читает ограниченный хвост журнала; старые строки с учётными данными фильтруются, соответствующее native-логирование удалено.
- Изменения native-кода применяются воспроизводимо к копии исходников через BuildHevTunTask. Исходный Git-подмодуль не требуется менять. Патч проверяет ожидаемые фрагменты и имеет версию входа runtime-readiness-v1.
- Собраны JNI и CLI для четырёх ABI. Для arm64 проверены наличие TProxyIsReady, отсутствие диагностических строк с паролем и ELF LOAD alignment 0x4000.

### Android и общий Home

- Исправлены неверный импорт режима latency, несовместимость Int настройки subscriptionPingMode и локальный порядок объявления launcher.
- Координатор latency сохраняется между recomposition и использует актуальное состояние. Все типы проверки проходят через согласованное управление операцией.
- Набор серверов группы берётся из текущего Home input, включая «Все» и AutoBalancer.
- Run-id защищает новые задания от завершающихся callback отменённых заданий; фактическая занятость платформы участвует в блокировке действий.
- Исправлен тестовый fixture группы с отсутствовавшим enabled.
- Сортировка Desktop не дублирует сортировку общего Store.
- Исправлен контраст compact hero, кнопок и toolbar при светлом акценте в тёмной теме.
- Общая карточка подписки отображает нулевой/неположительный лимит как ∞. Эта ошибка обнаружена на реальном Desktop-снимке.
- Удалён Home-переключатель отключения подписки на обеих платформах; сохранённое состояние enabled остаётся читаемым.
- Сохранены ленивый список со стабильными ключами, доступная кнопка подключения в wide compact, корректная подпись групп и запрет ping пустой группы.
