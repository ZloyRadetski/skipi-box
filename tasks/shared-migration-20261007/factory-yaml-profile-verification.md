## Уже начатый P02 research: без реализации

Read-only audit завершён после просьбы пользователя о паузе; production/tests P02 не изменены.

- Android oracle уже находится в shared/app `TrafficConfigCollectionOperations` и `TrafficConfigDocumentImport`. Для create/duplicate/delete/import нет соответствующих characterization tests; они должны предшествовать следующему переносу.
- Android duplicate всегда создаёт новый ID в конце, копирует source/settings, обнуляет timestamp и сохраняет active ID. Desktop screen направляет копию в `put` с прежним source URL; его URL dedup заменяет исходный профиль вместо создания второго. Это кандидат на следующий behavioral RED.
- Android не удаляет последний профиль. Desktop collection remove позволяет это; inline delete запрещён, но context-menu delete не имеет такого guard.
- Android import replacement сохраняет индекс; Desktop `put` переносит matched item в конец. Android отдельный URL-dialog создаёт новый профиль без merge; clipboard/deep-link/document import выполняет merge и активирует по своим правилам только новый профиль. Эти пути нельзя объединить в один generic upsert. Profile reorder Android route не найден; его не добавлять.
- Desktop screen сохраняет captured whole-library snapshot и обходит current-state repository; отложенный save/import может затереть более новый state. Следующий P02 lifecycle adapter должен применять operation к latest collection.
- Android имеет persisted `nextTrafficConfigId`, текущий Desktop configs.json — нет. Политика no-reuse после удаления максимального ID и рестарта требует отдельного решения о persisted counter/migration; сохранить совместимость старого JSON. Это исследовательский вопрос следующего среза, не разрешённое изменение текущего storage schema.
- Первый возможный срез при возобновлении — characterization create/duplicate/delete/select, Desktop duplicate/last-delete RED и distinct operations для duplicate/import. Затем отдельные import modes/stale saves. Profile-group reconciliation/schedulers остаются P03. Пока этот срез не начат.
